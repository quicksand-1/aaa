# 组件技能更新器

这个技能帮助你更新组件技能文件，使其与组件文档和源码保持一致。它可以自动分析组件的文档和源码，然后更新对应的技能文件，确保技能内容准确、完整且最新。

## 使用方法

### 输入格式

```
update 组件名 skill
```

或

```
更新 组件名 技能
```

### 示例

| 输入                    | 含义                            | 输出                                     |
| ----------------------- | ------------------------------- | ---------------------------------------- |
| `update LinkBtn skill`  | 更新 LinkBtn 组件的技能文件     | 更新 `.trae/skills/LinkBtn/SKILL.md`     |
| `更新 AsyncSwitch 技能` | 更新 AsyncSwitch 组件的技能文件 | 更新 `.trae/skills/AsyncSwitch/SKILL.md` |

## 工作流程

1. **接收输入**：解析用户输入的组件名
2. **查找文件**：
   - 组件文档：`docs/components/组件名.md`
   - 组件源码：`src/组件名/index.tsx`
   - 技能文件：`.trae/skills/组件名/SKILL.md`
3. **分析组件**：
   - 读取组件文档，了解组件的功能和 API
   - 读取组件源码，分析组件的实现
4. **更新技能**：
   - 根据组件文档更新示例代码
   - 根据 API 文档更新属性说明
   - 确保技能内容与组件文档保持一致
5. **添加参考文档**：
   - 添加组件文档链接（相对路径）
   - 添加组件源码链接（相对路径）
   - 添加组件分析报告链接（相对路径）
6. **返回结果**：在对话中返回更新摘要

## 更新内容规范

### 示例代码更新

- 根据组件文档中的示例更新技能中的示例代码
- 确保示例覆盖所有主要使用场景
- 保持示例代码的简洁性和可读性

### API 文档更新

| 项目     | 要求                                     |
| -------- | ---------------------------------------- |
| 属性说明 | 根据组件文档更新属性说明                 |
| 属性类型 | 确保属性类型准确                         |
| 默认值   | 确保默认值准确                           |
| 描述     | 确保描述准确                             |
| 特殊用法 | 添加特殊用法的说明（如 params 特殊用法） |

### 参考文档添加

必须添加以下三个参考文档链接（使用相对路径）：

- **组件文档**：`docs/components/组件名.md`
- **组件源码**：`src/组件名/index.tsx`
- **组件分析报告**：`document/组件名/README.md`

## 何时使用此技能

- 更新组件技能文件，使其与组件文档保持一致
- 为新组件创建技能文件
- 优化现有组件技能的内容和结构
- 确保技能文件包含最新的 API 信息和示例

## 注意事项

| 项目             | 说明                           |
| ---------------- | ------------------------------ |
| 组件文档路径     | `docs/components/组件名.md`    |
| 组件源码路径     | `src/组件名/index.tsx`         |
| 技能文件路径     | `.trae/skills/组件名/SKILL.md` |
| 路径类型         | 所有路径都是相对路径           |
| description 字段 | 必须包含"何时调用"的说明       |
| 提示词语言       | 生成中文提示词                 |
